# {% include icon.html icon="fa-solid fa-microscope" %}研究方向

课题组面向航空航天、核工业等极端环境应用需求，围绕**耐高温、抗辐照 MEMS 传感器件**开展研究，涵盖器件设计、微纳制造、封装与可靠性评估等方向。

- **耐高温压力传感**：面向 500°C 以上高温环境的高灵敏度压力传感结构设计
- **抗辐照封装与可靠性**：器件在辐照、热循环等耦合环境下的失效机理与加固方法
- **微纳加工工艺**：MEMS 关键工艺的开发、优化与表征
